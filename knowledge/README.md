# PriceMind AI Enterprise Knowledge Base

Welcome to the PriceMind AI RAG (Retrieval-Augmented Generation) knowledge repository.
This knowledge base contains curated enterprise documentation, domain policies, mathematical methodologies, model architectures, and data dictionaries.

## Repository Structure
- `pricing/`: Pricing policies, governance guardrails, discount matrices, and business constraints.
- `models/`: Machine learning architecture, feature engineering definitions, and econometric elasticity methodology.
- `optimization/`: Dynamic pricing optimization formulations, solver algorithms, and constraint specifications.
- `forecasting/`: Demand forecasting algorithms, horizon methodologies, and decomposition techniques.
- `explainability/`: SHAP tree explainer methodologies, game-theoretic attributions, and waterfall decompositions.
- `data_dictionary/`: Schema definitions and business semantics for all 88 engineered features.

## Grounding Principle
All information in this repository serves as authoritative ground-truth for the AI Assistant.
Numerical calculations (real-time demand predictions, optimal prices, live revenue KPIs) are executed dynamically by the underlying ML and Optimization engines and are not fabricated by the language model.
